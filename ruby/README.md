# Sudoku Generator API - Ruby Gem

Sudoku Generator creates 9x9 Sudoku puzzle grids across multiple difficulty settings, with empty cells marked as zeros. Paid plans add the full solution grid for validation or hints.

## Installation

Add this line to your application's Gemfile:

```ruby
gem 'apiverve_sudoku'
```

And then execute:

```bash
$ bundle install
```

Or install it yourself as:

```bash
$ gem install apiverve_sudoku
```

## Getting Started

Get your API key at [APIVerve](https://apiverve.com)

### Basic Usage

```ruby
require 'apiverve_sudoku'

# Initialize the client
client = APIVerve::Sudoku::Client.new(api_key: "YOUR_API_KEY")

# Make a request
response = client.execute({ difficulty: "medium" })

# Print the response
puts response
```


### Error Handling

```ruby
begin
  response = client.execute({ difficulty: "medium" })
  puts response["data"]
rescue APIVerve::Sudoku::ValidationError => e
  puts "Validation error: #{e.errors.join(', ')}"
rescue APIVerve::Sudoku::APIError => e
  puts "API error: #{e.message}"
  puts "Status code: #{e.status_code}"
end
```

### Debug Mode

```ruby
# Enable debug logging
client = APIVerve::Sudoku::Client.new(
  api_key: "YOUR_API_KEY",
  debug: true
)
```
